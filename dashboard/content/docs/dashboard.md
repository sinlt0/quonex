# Dashboard

Sign in with Discord from the dashboard. You'll only see servers where you have Manage Server permission (or you're the owner) *and* the bot is actually in that server.

## Overview

Prefix, premium status, panel count, and open ticket count at a glance.

## Tickets

A read-only list of currently open tickets — number, opener, who's claimed it, and when it was opened.

## Panels

A read-only list of your panels, showing how many staff roles and intake questions each one has.

## Settings

Read-only for now — current prefix, premium status, and no-prefix mode. Editing from the dashboard is planned for a future update; use the bot's commands to change these in the meantime.
