# Premium & No-Prefix

## Premium

Premium is duration-based rather than tiered — a server has it for a set length of time (or forever, if granted for life), not a subscription level. It raises the limits on panels, active tickets, staff roles per panel, and intake questions per panel.

Redeem a key with `premiumclaim <key>` (any Manage Server holder can do this). If your server already has time remaining, redeeming a new key stacks on top rather than replacing it.

## No-Prefix

Normally, text commands need your server's prefix in front of them. No-prefix access lets specific accounts run those same commands bare, with no prefix at all.

- Premium servers can enable it for everyone with `np enable`, or for specific people with `np enableuser @user`
- `np disable` / `np disableuser @user` turn it back off

No-prefix and the commands that manage it don't have slash versions — they're prefix/text commands only.
